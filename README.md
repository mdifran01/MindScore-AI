# 🧠 MindScore AI — Mental Health Prediction System

An end-to-end Machine Learning web application that predicts a student's **mental health score** based on academic habits, social media usage, lifestyle patterns and perceived stress level.

The project combines a trained Machine Learning model with a **FastAPI backend** and a modern web frontend to provide real-time predictions.

> ⚠️ **Disclaimer:** This project is intended for educational and informational purposes only. The prediction is generated by a Machine Learning model and is **not a medical diagnosis or professional mental health assessment.**

---

## 🚀 Project Overview

Student mental health can be influenced by several factors such as:

- Daily social media usage
- Number of phone unlocks
- Study hours
- Physical activity
- Sleep duration
- Academic level
- Stress level
- Social media platform usage
- Purpose of social media usage

**MindScore AI** takes these factors as input and uses a trained Machine Learning model to estimate a mental health score on a **0–10 scale**.
